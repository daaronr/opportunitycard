# OpportunityCard

Source for https://daaronr.github.io/opportunitycard/, the project page for David
Reinstein's OpportunityCard proposal (voluntary, income-verified discounts). It links the
2015 Essex discussion paper, the shorter versions, The Conversation article, outside
discussion, and the 2026 reassessment.

- `index.html` is the whole site (static, no build). GitHub Pages publishes it from `main`.
- Comments come in through Hypothes.is (embedded on the page).
- The 2026 reassessment is a separate Netlify site, https://opportunitycard-ten-years-on.netlify.app,
  whose source lives in the private project archive (Dropbox `poorcard/netlify_opportunitycard/`).
- Only public material goes here. The private archive holds unpublished drafts and named
  correspondence that must not be linked or quoted.

To add a new post or outside discussion, add an `<li>` to the relevant timeline in
`index.html` and push.
